# تحديث مهلة التقارير وربط التدقيق وتنسيق الهوية

- مهلة افتراضية مقدارها 3600 ثانية للنموذج والتخطيط وطلب التقرير، بما في ذلك
  الكتالوج وتصدير التدقيق. يدعم محلل خيارات المخطط الآن ساعة كاملة؛ الحد السابق
  كان 600 ثانية. التشغيل عبر المشرف أو خدمة Windows يمرر إعدادات الساعة إلى الويب
  والمخطط. في التشغيل اليدوي قد تتجاوز الملفات المحلية أو متغيرات البيئة الافتراضيات.
- إعداد ربط Audit Trail وفحص التصدير من تبويب الوثائق والنظام، مع حساب Windows
  مستقل ومشفّر في جلسة المستخدم. أخطاء الاتصال والصلاحيات والمسارات لا تصبح أعدادًا صفرية.
- ضبط تباعد الهيدر والخط والزخرفة والأزرار مع الهوية الحالية، وتعديل العنوان إلى
  «اسأل عن وثائقك».
- تسجيل الخروج يلغي الطلبات الجارية ويُنهي الجلسة ويحاول إغلاق التبويب. إذا رفض
  المتصفح إغلاق تبويب فتحه المستخدم، ينتقل إلى صفحة تسجيل خروج خالية من التقارير.

## تطبيق التحديث

يجب إعادة بناء ونشر الويب وإعادة تشغيل المخطط. سحب Git وحده لا يحدّث الملفات
المنشورة في مجلد التثبيت أو IIS. لا تستخدم --no-build قبل بناء النسخة الجديدة.
تثبيت Windows القديم بالتشغيل التلقائي يُحدّث عبر unregister.ps1 ثم install.ps1.
نسخة MSI تتطلب إعادة بناء المثبّت من المصدر الجديد؛ ملف Setup قديم لا يتغير بسحب Git.
لا تستبدل ملفات إعدادات الجهاز الثاني بقيم جهاز التطوير. احفظ ملفات الإعدادات المحلية
قبل تحديث النشر، واستعمل الموديل والمنفذ المعتمدين في ذلك الجهاز.

## نطاق التحقق

الاختبارات تستخدم خدمات محاكاة وتتحقق من عزل الجلسات وحفظ الإعدادات والتصدير
والتخطيط وعرض التقارير. يلزم فحص الاتصال من الجهاز الفعلي لقبول ربط Audit Trail،
ومقارنة أسئلة الحذف بأحداث معروفة في التقرير المحفوظ. لا يثبت اختبار المحاكاة صحة
كل تفسير لغوي للموديل أو اكتمال التغطية التاريخية للمستودع.

نتائج الفحص المحلي: نجح بناء Release؛ 446 حالة C# نجحت وحالة قاعدة بيانات
خارجية واحدة مؤجلة. شُغلت حالات C# عبر منفّذ انعكاس محلي لأن مشغّل VSTest
في بيئة العمل تعطل قبل بدء الاختبارات؛ يبقى dotnet test المعتاد في CI هو بوابة الإصدار.
اكتمل فحص Python: 173 حالة، منها حالة اختيارية مؤجلة، ونجحت حالات الواجهة الـ25.
نجح فحص متصفح على 1440×1000 و390×844، بما فيه إعداد التدقيق وفحصه وتسجيل
الخروج، باستخدام API محاكاة. نجح بدء مضيف الويب وإرجاع 401 لطلبات التدقيق المجهولة.
لم يُختبر اتصال بخادم Laserfiche أو Audit Trail فعلي في هذه البيئة.
